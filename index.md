## Evidence and Research Limitations

Evidence-status labels apply to bounded statements: documented science, technical guidance, experimentally demonstrated capability, research hypothesis, personal observation, or unverified claim. A publication about a physical effect does not establish that it occurred in a specific event. The [bibliography's unresolved questions](docs/research/PHASE-2A-SCIENTIFIC-BIBLIOGRAPHY.md#research-gaps-and-unresolved-questions) and [research limitations](manual/04-technology-research.md#research-and-attribution-limits) identify what remains open.

## Documentation and Contributions

The repository's [investigative methodology](manual/05-investigative-methodology.md), [evidence preservation guidance](manual/06-evidence-preservation.md), [versioning policy](governance/VERSIONING.md), and [anti-drift policy](governance/ANTI_DRIFT.md) describe documentation and preservation practices. ## Site Deployment and Search Metadata

This is a Markdown-based Jekyll site using the GitHub Pages Minima theme with descriptive title and page-description metadata; it adds no custom JavaScript framework or third-party tracking. GitHub Pages is not currently configured for this repository. To deploy, a maintainer must select the `main` branch and root folder in repository Settings > Pages, then confirm the resulting URL. No deployment URL, canonical host, sitemap, public deployment, or search-engine indexing is asserted. After the URL is confirmed, set `url` and `baseurl` in the [Jekyll configuration](https://github.com/the-resistance/Gangstalking-Countermeasures/blob/main/_config.yml), then add a sitemap directive or sitemap generator using that confirmed absolute URL.
